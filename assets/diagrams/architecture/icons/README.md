# AI system diagram icons

The renderer reads these SVG files locally and embeds the marks in the final PNG.

- Next.js, Go, Firebase, Redis and GitHub Actions come from the Thoth technology icon collection and use Devicon artwork. [Devicon source](https://github.com/velrino/devicon/tree/75c8d3d001d81810abf322b234c1ffacf0ab518c/icons) · [Devicon license](LICENSE)
- The Gemini mark comes from the same local collection. [Gemini icon and source credits](https://github.com/velrino/devicon/blob/75c8d3d001d81810abf322b234c1ffacf0ab518c/icons/SOURCES.md)
- The LangChain mark comes from Simple Icons and identifies the framework used by LangChainGo. [LangChain artwork](https://github.com/simple-icons/simple-icons/blob/develop/icons/langchain.svg)
