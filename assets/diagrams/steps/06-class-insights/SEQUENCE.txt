    %% First-use headers introduce existing participants visually.
    %% This is the queued success path, followed by an open teacher dashboard.
    %% The summary event invalidates the page. It is not the API response.
    autonumber
    participant Redis
    Note over Redis: Ready for class refresh<br/>Evidence and pending intent<br/>were saved together.

    create participant Worker
    Redis->>Worker: Deliver the versioned class refresh job
    activate Worker
    create participant DB
    Worker->>DB: Claim the pending generation<br/>Check class scope and acquire the owner token
    DB-->>Worker: Claimed generation and tenant scope
    Note right of DB: Durable refresh intent<br/>class_learning_refreshes/{class_id}<br/>Owner token and 5-minute lease

    Worker->>DB: Read current class evidence<br/>Up to 100 latest finalized students
    DB-->>Worker: Source-validated student evidence
    Note over Worker,DB: Pending work survives failures.<br/>Old or completed jobs do no work.<br/>Busy claims retry. Recovery scans pending intents.

    create participant LLM
    Worker->>LLM: Build a bounded class synthesis<br/>Cluster only the supplied evidence
    activate LLM
    LLM-->>Worker: Strength and need clusters plus adaptation
    deactivate LLM
    Note right of LLM: Bounded class memory<br/>Up to 4 strengths and 4 needs<br/>Next adaptation: 280 characters<br/>Observed fallback if the model is unavailable

    Worker->>DB: Commit the class summary<br/>Recheck owner, lease, tenant and source generation
    Note right of DB: Atomic completion<br/>class_learning_summaries/{class_id}<br/>Advance completed_generation with the summary
    DB-->>Worker: Summary and completed generation saved
    Worker-->>Redis: Complete delivery
    deactivate Worker

    create participant Teacher
    DB-->>Teacher: Summary changed - invalidate the visible page
    Note over Teacher: Dashboard already open<br/>Realtime invalidation or a visible-page<br/>refresh every 15 seconds
    create participant API
    Teacher->>API: Refresh the selected class overview<br/>GET /dashboard/overview/page with class and cursor
    activate API
    API->>DB: Check teacher access and read overview<br/>Current roster page, latest evidence and stored summary
    DB-->>API: Authorized overview records
    API-->>Teacher: Page-scoped class insights<br/>Strengths, needs and next-step guidance
    deactivate API
    Note over Teacher,API: Page-scoped teacher view<br/>Current page evidence drives its patterns.<br/>The legacy route can also use stored synthesis.
