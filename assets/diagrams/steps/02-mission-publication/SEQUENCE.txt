sequenceDiagram
    %% First-use headers introduce existing services visually.
    %% They do not create infrastructure or service instances.
    %% File-copy execution belongs to step 03.
    autonumber
    participant Teacher

    Teacher->>Teacher: Review the draft and edit if needed
    create participant API
    Teacher->>API: Publish with expected_draft_revision<br/>and optional reviewed edits
    activate API
    API->>API: Validate the request and teacher identity

    create participant DB
    API->>DB: Load the teacher class and mission draft
    DB-->>API: Owner, scope, revision and guardrails
    API->>API: Check access, draft revision and content policy
    Note right of API: Rejected requests stop before enqueue.<br/>400 missing revision, 403 access,<br/>409 stale draft, 422 blocked content

    opt Files need transfer, draft not already published, jobs enabled
        create participant Redis
        API->>Redis: Enqueue copy job for class, mission and revision
        Redis-->>API: Job accepted or queue failure
        break Configured queue rejects the job
            API-->>Teacher: 503 attachment_queue_unavailable
        end
    end
    Note over API,Redis: Enqueue happens before the DB transaction.<br/>Workers process the job in step 03.
    Note right of API: With jobs disabled, skip enqueue.<br/>Publication can still continue.

    critical Firestore publication transaction
        API->>DB: Recheck owner and expected revision<br/>Apply edits and publication writes
        activate DB
        Note right of DB: missions/{mission_id}/<br/>published_revisions/{revision}<br/>Also update class active_mission_id<br/>and the audience-safe student catalog.
        DB-->>API: Committed or revision conflict
        deactivate DB
    end
    Note over API,DB: An unchanged publication without inline edits reuses the revision.<br/>Class activation and the student catalog can still refresh.

    alt Draft revision changed before commit
        API-->>Teacher: 409 draft_conflict - review the latest draft
    else Transaction committed
        API-->>Teacher: Published mission and published_revision
    end
    deactivate API
