# Documentation

Start with the task you need to complete. Each guide owns one topic; package `AGENTS.md` files route AI work into this tree.

| Task | Start here |
| --- | --- |
| Run the application | [Local setup](development/LOCAL-SETUP.md) |
| Check a change | [Validation](development/VALIDATION.md) |
| Understand system/module boundaries | [Architecture](architecture/README.md) |
| Work with coding agents or AI quality | [AI](ai/README.md) |
| Use routes, configuration, or stored data | [Reference](reference/README.md) |
| Review or integrate a release | [Processes](processes/README.md) |
| Operate or recover a deployment | [Operations](operations/README.md) · [Release safety](operations/RELEASE-SAFETY.md) |
| Add or update documentation | [Documentation standard](conventions/DOCUMENTATION.md) |
| Follow refactor acceptance criteria | [Plans](plans/README.md) |
| Review the historical submission | [Pitch archive](pitch/README.md) |

| Folder | Owns |
| --- | --- |
| [architecture/](architecture/README.md) | System, capability boundaries, tutor safeguards |
| [development/](development/README.md) | Local setup and validation |
| [ai/](ai/README.md) | Agent workspaces and evaluation guidance |
| [conventions/](conventions/README.md) | Documentation placement and maintenance |
| [processes/](processes/README.md) | Code review and Git integration |
| [operations/](operations/README.md) | Runtime operations and dated hosting history |
| [reference/](reference/README.md) | API contracts, configuration, data ownership |
| [plans/](plans/README.md) | Intended changes and acceptance criteria |
| [pitch/](pitch/README.md) | Historical product/submission material |

Living guides describe the supported workflow and must match the code. Plans describe intent; completion needs implementation and validation evidence. Historical records describe their date, not current hosting, access, or feature availability.

The [root router](../AGENTS.md), [API guide](../api/AGENTS.md), [web guide](../web/AGENTS.md), and [agent contract](../agents/AGENTS.md) remain scoped entry points. Package READMEs are concise starting points. Asset provenance stays [beside its files](../assets/3d/avatars/chibi-band/README.md).
